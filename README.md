Paddy Disease Classification Using Deep Learning

Project Description

This project focuses on identifying and classifying diseases in paddy leaves using Deep Learning and Convolutional Neural Networks.

Objective

To develop an automated system that identifies different paddy leaf diseases from images and helps in early disease detection.

Technologies Used

•⁠  ⁠Python
•⁠  ⁠TensorFlow
•⁠  ⁠Keras
•⁠  ⁠CNN (Convolutional Neural Network)
•⁠  ⁠EfficientNetV2S
•⁠  ⁠NumPy
•⁠  ⁠Scikit-learn
•⁠  ⁠Kaggle Notebook

Model Architecture

•⁠  ⁠EfficientNetV2S Transfer Learning
•⁠  ⁠Global Average Pooling
•⁠  ⁠Dropout Layer
•⁠  ⁠Dense Classification Layer
•⁠  ⁠Softmax Activation

Dataset

Paddy disease image dataset obtained through Kaggle.

Implementation

1.⁠ ⁠Dataset loading
2.⁠ ⁠Image preprocessing
3.⁠ ⁠Data augmentation
4.⁠ ⁠Transfer learning using EfficientNetV2S
5.⁠ ⁠Model training and validation
6.⁠ ⁠Disease classification and evaluation

How to Run

1.⁠ ⁠Open the notebook using Kaggle.
2.⁠ ⁠Add the required dataset.
3.⁠ ⁠Run the notebook cells sequentially.
4.⁠ ⁠Evaluate the trained model.
